# 지도 단계구분도 (구간별 색상)

출력 레이어를 오른쪽 클릭한 뒤 **구간별 색상...** 을 선택합니다.

숫자 속성값을 여러 구간으로 나누어 폴리곤 색상으로 표현합니다. 분류 방법(자연구간/등간격/분위수/사용자 정의)과 색상표를 고른 다음 미리보기로 범례를 확인하고 적용하면 GeoServer named style이 등록됩니다.

- WMS: GeoServer `STYLES` 파라미터로 서버 렌더링
- WFS: 동일한 분류 JSON으로 OpenLayers 벡터 스타일
- 초기화: 단계구분도 스타일을 해제하고 기본 스타일로 복구 (레이어 자체는 삭제하지 않음)
- 코드·ID 열(`sgis_cd` 등)은 목록 뒤로 보내고, 지표 열을 기본 선택에 가깝게 둔다.
